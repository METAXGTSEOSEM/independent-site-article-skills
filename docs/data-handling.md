# Data handling and permissions

## What the Skill reads

- The brief and files you provide.
- Public pages when research access is available and you ask for research.
- The Skill's own references and templates.

## What it writes

- Drafts, source records, claim records, review reports and field packs in the
  workspace you provide.

## What it does not do by default

- It does not publish, schedule or modify a live WordPress site.
- It does not read a CMS, analytics account or ad account without separate
  access and authorization.
- It does not send your brief or drafts to the repository maintainer.
- It does not run a telemetry service.

## External services

The required language editor is installed separately from this repository. Web
research tools, model providers and CMS connections may have their own data
handling terms. Review those terms before using confidential material.

## Secrets

Do not put passwords, API keys, customer lists or private support messages in a
brief. If a task needs account access, use the host's approved connection rather
than pasting credentials into the prompt.

## Human approval

The workflow can prepare and review content, but a human remains responsible
for factual accuracy, legal claims, image rights and the decision to publish.
